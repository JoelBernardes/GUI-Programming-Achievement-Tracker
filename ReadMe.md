# Achievement Tracker V0.0.0
## What does it do?
This application is a UI Overlay for gamers who are interested in 100% completing games by obtaining all the achievements
possible while being able to add your own custom achievements and be able to track that progress during the game versus
having to tab to alt tab or go to a separate screen to see achievement status.

## How to use the interface?

To use our application, the user must have a game open and link their steam account to our application to be able to
properly get their achievement statistics as well as have a game open to be able to pull the achievements they are attempting
to obtain for the game that they are playing. This will be done via an executable such that when you open it, you would
be able to begin tracking achievements for a game that you are playing while still being able to play the game at that 
given time.
